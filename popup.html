⚙️ Configure (One-Time Setup)
1. Open the Configure tab in this popup
2. Add GitHub token, username, repository, branch, and solutions folder
3. Add your API key for AI analysis
4. Click 💾 Save Settings
5. Click 🔍 Test Connection to verify GitHub + AI are reachable
🚀 How To Use
1. Open any LeetCode problem page
2. Write your solution in the editor
3. Use one of the three buttons (explained below)
4. Check your GitHub repository after push completes
🔘 Three Buttons (Updated Behavior)
🧠 Get Approach
• Shows only the approach panel (thinking/analysis)
• Does not push to GitHub

📤 Push to GitHub
• Shows approach panel first
• Panel includes push button; push happens only when you confirm

⚡ Floating Button (bottom-right)
• Instant push flow
• No side panel opens
📁 What Gets Pushed
One file per problem is pushed to:
solutions/difficulty/NNNN-problem-name/solution.md

That single solution.md includes:
• Problem statement and metadata
• AI approach explanation
• Your submitted code + complexity
• AI-optimized code + complexity
🔑 Getting API Keys
GitHub Token: github.com/settings/tokens → Select repo scope

Groq API Key: console.groq.com/keys → Free tier, generous limits

Model used: openai/gpt-oss-120b
⚠️ Code Not Detected?
Use the ⚡ floating button bottom-right of LeetCode, or the 📤 Push to GitHub button near the problem description. Both trigger manual extraction.
